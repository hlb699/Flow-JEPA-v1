# 随机 PushT 评测结果（2026-10-20）

已完成随机动力学环境及现有模型评测，**没有训练，没有改写原始 HDF5 数据集**。
从原数据集抽取起点和未来目标，在在线模拟器中改变动力学。
本轮参数下，每步随机外力带来的成功率下降最大，接触转向次之。

## 模型与评测协议

- Checkpoint：`stable-wm/checkpoints/flow-jepa-pusht-paper-1gpu-strict/weights_epoch_20.pt`。
- SHA-256：`409ec3a1eec4bc6a229078022281cd6a6f5c5589fe454f0b868de7bf09704dda`。
- 数据集：`pusht_expert_train.h5`，只读使用。
- 8 组各 50 个配对任务，采样 seed=42，环境 seed=42 至 91。
- 各组使用完全相同的数据集 episode、起始步、实际初始状态、目标及初始图像。
- 目标为起点之后 25 步的状态，执行预算 50 个控制步。
- CEM：300 个候选，10 轮；预测 horizon=5，action block=5，每 25 个实际控制步重新规划。
- 成功标准沿用当前安装的 PushT：推杆与 T 块位置拼接后的 L2 误差 <20 像素，且 T 块角度环绕误差 <π/9；不是单纯的 T 块覆盖率。
- 干净组复现此前结果 44/50（88%）。新评测器通过 reset options 设置数据集起点与目标，并将模拟器实际图像交给模型。

## 随机动力学实现

实现入口：[stochastic_pusht.py](../stochastic_pusht.py)。

| 因素 | 本轮设置 | 采样时机 |
| --- | --- | --- |
| 质量 | 原质量乘以 Uniform(0.5, 2.0)，转动惯量同比缩放 | 每局一次 |
| 摩擦 | 推杆/T 块有效接触摩擦系数 Uniform(0.1, 1.0) | 每局一次 |
| 外力 | 世界坐标 x/y 独立 Normal(0, 2000²)，作用于 T 块质心 | 每个控制步重新采样 |
| 接触转向 | 对 T 块角速度加入等概率 -5 或 +5 rad/s | 每个发生推杆/T 块接触的控制步至多一次 |

控制频率 10 Hz，每个控制步包含 10 个 0.01 秒物理子步。外力在全部子步中持续作用，
原质量为 1 时，自由状态下每个坐标轴每步位移标准差约 2 像素。
接触转向改变角速度，位置和角度保持连续；墙面接触不触发。
持续接触可在下一个控制步再次触发。原模拟器 damping=0，因此单次角速度扰动通常造成约 0.05 rad 的角度变化；具体效果取决于接触和触发子步。

质量、摩擦、外力和转向使用独立的随机数流。所有扰动在 reset 的原始静置过程结束后才启用，
保证各组起点一致。参数和扰动不进入策略输入、不改变渲染，只保存为诊断信息。

**摩擦的具体含义：**当前模拟器没有显式桌面接触模型，这里实现的是推杆与 T 块之间的接触摩擦，
不是 T 块在桌面上的滑动摩擦。原代码虽然设置 `Body.friction=1`，但引擎实际使用的
`Shape.friction` 均为 0。随机环境将推杆 shape 系数设为 1，T 块两个 shape 设为采样值，
两者乘积就是有效摩擦系数。另设固定 μ=0.55 的对照，用于区分改变接触机制与摩擦随机性的影响。

## 结果

| 评测组 | 成功数 | 成功率 | Wilson 95% 区间 | 相对干净组 |
| --- | ---: | ---: | ---: | ---: |
| 原始环境 | 44/50 | 88% | 76.2%–94.4% | 0 个百分点 |
| 固定接触摩擦 μ=0.55 | 41/50 | 82% | 69.2%–90.2% | -6 个百分点 |
| 仅随机质量 | 44/50 | 88% | 76.2%–94.4% | 0 个百分点 |
| 仅随机摩擦 | 42/50 | 84% | 71.5%–91.7% | -4 个百分点 |
| 随机质量与摩擦 | 42/50 | 84% | 71.5%–91.7% | -4 个百分点 |
| 仅每步随机外力 | 29/50 | 58% | 44.2%–70.6% | -30 个百分点 |
| 仅接触随机转向 | 37/50 | 74% | 60.4%–84.1% | -14 个百分点 |
| 全部组合 | 31/50 | 62% | 48.2%–74.1% | -26 个百分点 |

## 解释与限制

1. **每步随机外力是本轮最强的干扰因素。**原始成功的 44 局中有 16 局变为失败，同时原始失败中有 1 局变为成功，净减少 15 局。实际记录的 x/y 外力标准差约为 2008/1972，与设置一致。
2. **接触随机转向确实触发并影响结果。**50 局中 44 局发生推杆/T 块接触，共触发 615 次转向，其中正向 307 次、负向 308 次；原始成功中 7 局变为失败。组合组在 46 局中触发 674 次转向。
3. **质量单独变化不能有效检验本环境下的鲁棒性。**当前是运动学推杆、单个动态物体、无重力，且质量和转动惯量同比缩放。仅随机质量组与原始组动作完全相同，最大状态差仅 1.14e-13。质量加摩擦组与仅摩擦组动作也完全相同。质量在外力存在时仍通过 F/m 改变加速度，测试已验证质量加倍使自由位移减半。
4. **摩擦随机性的额外影响尚不明确。**随机摩擦 84%，固定均值摩擦 82%，相差仅 1 局；相对原始环境的变化也混合了从零摩擦改为非零摩擦的影响，不能直接归因于随机性。
5. **组合不必比每个单因素更难。**组合组 62%，高于仅外力的 58%；随机质量、摩擦和接触转向会共同改变运动，部分因素可能互相抵消。仅凭这 50 局不能断言组合优于单因素。
6. 这是单个模型、一个任务采样 seed 下的初步迁移评测，区间较宽。它说明环境可实现且能产生性能差异，不能证明模型学到了多模态未来或校准的不确定性。质量和摩擦属于每局固定的隐藏参数，外力和接触转向则持续引入新的随机性。

如果后续希望质量本身成为明显因素，需要加入桌面阻力模型，或将推杆改成力驱动的动态刚体；这会改变基准动力学，应另设干净对照。
本轮保留原始动力学结构，未做这些扩展。
